# On 문서

쓰기부터 결재 전 점검까지 — 한글(HWP·HWPX)·PDF·오피스 문서 도구

[웹에서 바로 쓰기](https://onmunseo.kr/app/) · [AI 도구에 붙이기(MCP)](https://github.com/on-munseo/on-munseo.github.io/blob/main/MCP.md) · [English](#english)

한글 문서를 브라우저에서 열어 보고 고치고, 원고를 공문서 꼴 한글 파일로 만들고, 결재 전에 점검하는 도구 모음입니다. 웹 편집기와 원격 MCP 서버(AI 도구에 붙이는 주소)로 씁니다. 저장소에는 안내와 연결 설정만 두고, 엔진·서버 코드는 공개하지 않습니다.

## English

On 문서 (On Document) is a set of tools for Korean HWP/HWPX, PDF and Office documents: a browser editor, government-style document writing, and pre-approval checks. It is used through a web editor and through remote MCP servers that AI tools connect to. The repositories hold guides and connection settings only; the engine and server code are not public.

| Product | What it does | Repository | MCP endpoint (after `https://onmunseo.kr`) |
|---|---|---|---|
| **On 문서** | Web editor (open, edit, check, save) + every MCP bundle below | [on-munseo.github.io](https://github.com/on-munseo/on-munseo.github.io) | `/mcp` |
| On 글꺼내기 | Text and tables from HWP/HWPX, PDF and Office files | [on-text](https://github.com/on-munseo/on-text) | `/mcp/text` |
| On 결재점검 | Pre-approval checks: format, spelling, dates, weekdays, amounts, list totals | [on-check](https://github.com/on-munseo/on-check) | `/mcp/check` |
| On 개인정보 가리기 | Find personal data; masked text or masked HWPX | [on-mask](https://github.com/on-munseo/on-mask) | `/mcp/mask` |
| On HWPX 만들기 | Markdown to HWPX, form filling, page images, PDF | [on-hwpx](https://github.com/on-munseo/on-hwpx) | `/mcp/hwpx` |
| On 공문서 쓰기 | Government-style HWPX reports, plans, press releases; tables, charts, diagrams | [on-gov](https://github.com/on-munseo/on-gov) | `/mcp/gov` |
| On 글 다듬기 | Bullet-style rewriting, spelling and spacing, plain words | [on-tidy](https://github.com/on-munseo/on-tidy) | `/mcp/tidy` |
| On 근거 | Korean statutes verbatim and citation checks (copy of the national law database) | [on-geungeo](https://github.com/on-munseo/on-geungeo) | `/mcp/law` |
| On폭 글꼴 (OnPok) | Free fonts whose character widths match fonts common in Korean documents (SIL OFL 1.1) | [napurrin/onpok-fonts](https://github.com/napurrin/onpok-fonts) | — |
| On 한글엔진 | The engine inside On 문서 that reads and renders HWP/HWPX | private | — |

- **Start with one URL:** `https://onmunseo.kr/mcp` carries the document tools and the law tools together. Bundle endpoints are for adding a single feature set.
- **Works without a key** as a guest (50 calls a day and 6 a minute per internet address, 6 MB per request). For more, or for text recognition, PDF output and page images, request a key at `onmunseo.key [at] gmail.com`.
- Send only public documents or your own. Documents are handled in server memory and discarded after processing.
- Questions and bug reports: [issues](https://github.com/on-munseo/on-munseo.github.io/issues). [Terms of use](https://onmunseo.kr/terms) · [Privacy policy](https://onmunseo.kr/privacy) (Korean).
